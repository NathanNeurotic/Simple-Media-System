==============================================================================
  SMS.lng  --  translating Simple Media System
==============================================================================

WHAT THIS IS
  SMS.lng is a plain-text language file, one UI string per line, in a FIXED
  order. It is the same idea as a POPSLoader language file: hand SMS.lng to a
  translator, they replace each English line with their language, done.

HOW SMS USES IT
  * On a memory-card boot SMS reads  mc0:/SMS/SMS.lng
  * On a USB/HDD/network/UDPFS boot it reads  SMS.lng  next to the SMS.ELF (CWD)
  * Or import it in-app: SMS menu -> Device settings -> "Update SMS.lng file"
  * Then set  SMS menu -> Browser settings -> Language  to anything other than
    "English" for the file to take effect.

THE FIVE RULES (break any one and SMS silently ignores the WHOLE file and
falls back to English -- there is no error message):
  1. EXACTLY 311 lines. Do not add or remove a line. One English line in ->
     one translated line out, same position.
  2. NEVER leave a line blank. An empty line makes the parser stop early, the
     line count no longer equals 311, and the entire file is rejected. If a
     string should stay untranslated, copy the English text verbatim -- do not
     blank it.
  3. Keep every  %s  %d  %.1f  %02d  etc. EXACTLY as-is (same specifiers, same
     order). They are replaced at runtime with filenames, numbers, sizes.
     Lines flagged HAS-FORMAT below have these.
  4. Do NOT translate path entries 166, 167 in the zero-based reference below
     -- flagged LOCKED-PATH.
     They are boot-file paths, not text. Copy them verbatim.
  5. Save as plain text. ASCII or the code page that matches SMS's Character
     Set (Browser settings -> Character set: WinLatin1 / WinLatin2 / Cyrillic /
     Greek). CRLF or LF line endings are both fine; UTF-8 is NOT -- SMS renders
     single-byte encodings.

NEW IN THIS BUILD: entries 269..310 (zero-based below) extend UI that used to be English-only
(device menu: MX4SIO / HDD BDM / i.LINK / MMCE / UDPFS start+autostart; the UDPFS
and ATA start/error messages; the on-screen keyboard; the SMB server editor). In
most shipped community packs these tail entries are still ENGLISH placeholders --
that is where translation is now needed. Keep device/protocol proper-nouns
(MX4SIO, UDPFS, i.LINK, MMCE, HDD BDM) verbatim; translate the words around them.

TIP: keep lines about the same length as the English. The GUI has fixed widths;
very long strings can overflow their box.

INSTALLING A FINISHED TRANSLATION (from the legacy pack's own readme)
  1. Rename your file to  SMS.lng   (case sensitive)
  2. Copy it to  mc0:/SMS   (or next to SMS.ELF on USB/HDD/UDPFS)
  3. Select / enable it in the SMS menu

The 19 community translations in docs/translation/ (BG CA CZ DE EN ES FR HU ID IT
NL PL PT PT-BR RU SE SK TR UA) were extended to 311 lines to match THIS build, so
they load as-is (new-feature lines show English until translated). They are the
best reference for tone/length. (TR had a pre-existing duplicate line that was
removed to realign it.)
