The maintained SMS fork

SMS was created by Eugene Plotnikov and developed by the PS2 homebrew community. This storage-focused fork adds MX4SIO, ATA/exFAT, i.LINK and MMCE paths, a folder-served UDPFS network drive, on-screen network configuration, USB/Bluetooth DualShock 3/4 input and updated artwork. You need a PS2 that can already launch homebrew; a hard disk or network adapter is optional.

The October development work adds folder shuffle, converter multi-audio output and text-subtitle burn-in, and fixes reproduced parser, streaming and frame-lifetime defects. Known issues distinguishes implemented fixes from the reports still awaiting affected-console tests. An optional poster-grid candidate is under development, with console acceptance pending.

Formats and limits

MediaCurrent routes
VideoMPEG-4 Part 2 / Xvid / DivX in AVI; mp4v in MP4; MPEG-1/2 in MPEG program streams. Format details.
MusicMP2/MP3/MPA, AAC/M4A, AC-3, FLAC, Ogg Vorbis and WMA v1/v2. Audio constraints.
Pictures and textBaseline JPEG, M3U playlists and external SRT/SUB/TXT subtitles. Existing AVI DXSB bitmap subtitles are a separate path.
Video dimensionsAt most 1024 pixels on either axis. This is an acceptance check, not a real-time playback guarantee.
FilesKeep each file below 4 GiB on every source, including exFAT.
TracksEight stream-table slots; MP4 and MPEG-PS retain at most seven streams to reserve a terminator. The converter allows video plus six audio tracks.
Unsupported videoH.264/AVC, H.265/HEVC, VP9, AV1 and WMV. An MP4 extension alone does not identify the video codec.

Earlier project documentation records successful standard-definition fixture playback. Those are useful starting profiles; generating the test-media pack in CI does not retest a console. High bitrate, resolution, audio workload and source throughput still matter.

Start with a small, known file

  1. Download and launch the standard ELF with your homebrew loader.
  2. Use a supported existing FAT32/exFAT volume, copy a small MP3 or conservative video onto it, and enable that source in Device settings.
  3. Pick the source, press Down to enter its files and Cross to open a file. Start opens settings from the browser; Triangle stops playback.
  4. If it fails, keep the file unchanged and follow the reporting checklist.

Read the controls, settings reference and language guide when you are ready to customize. Credits and preserved historical manuals retain the project's lineage.
