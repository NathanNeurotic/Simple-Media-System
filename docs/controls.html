Controls

The browser, video player, audio player and picture viewer use different button maps. Start from the context you are in.

Browser

ButtonAction
D-pad Left / RightChoose a device; from the file list return to device selection.
D-pad DownEnter the selected device's file list; move down within it.
D-pad UpMove up in the file list.
CrossOpen a folder or start the selected media file.
TriangleParent folder / back to the device list.
L1 / L2Page up / down in a long list.
StartOpen SMS settings.
Circle on a folderPlay all menu: Audio, Video or Images. Randomize playlist also affects video folders.
Circle on videoChoose an external subtitle manually.
Select + CirclePower off from the browser.

Video and audio

ButtonAction
SelectPause / timeline controls.
StartResume; during normal playback open the player menu.
TriangleStop and return to the browser.
Left / RightRewind / fast-forward; within a normal audio track, seek. Playlist transport can change entries.
Up / DownVolume.
Cross (video)Toggle on-screen timer; exit fast-forward/rewind preview.
Square (video)Cycle pan-scan/aspect modes.
L1 / R1 (video)Pan left / right; together reset pan/zoom.
Circle (video)Select V/A audio/video or S/V subtitle/video sync adjustment.
L2 / R2 (video)Decrease/increase the selected sync value by 10 ms; together reset it.

Do not apply a fixed offset to every NTSC file. One community workaround used V/A -00:060, a 60 ms setting, not a universal six-frame correction. Compare your actual file with the offset reset first.

Use the in-player menu for available audio/subtitle selections. Multiple audio tracks in a converted file still need a playback test in SMS.

Picture viewer

Cross or Right advances and Left goes back when a folder was opened with Play all → Images. A separately opened JPEG has no folder queue to advance through. Square toggles fit/actual size, Circle and R1 rotate, and Triangle returns to the browser.

Documentation keyboard shortcuts

On this website, / focuses search when you are not typing in a field. Up/Down chooses a result, Enter opens it and Escape closes results. On narrow screens the navigation button opens the guide list. Optional cursor orbs can be disabled and default off for reduced-motion/touch users.
