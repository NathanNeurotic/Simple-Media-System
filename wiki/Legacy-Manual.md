# Legacy Documentation Archive

The repository contains only a fragment of the original multilingual SMS manual. Its former English, Portuguese and Russian landing-page targets are not present, so they are not offered as working documentation here.

Use the maintained manual

 The current, source-checked documentation begins at [SMS Docs](https://nathanneurotic.github.io/Simple-Media-System/index.html). It covers the supported media formats, devices, networking, installation, settings and current release.

## Preserved encoding guide

The one complete legacy guide retained in this repository is pitrz's [high-resolution MPEG-2 encoding guide](https://nathanneurotic.github.io/Simple-Media-System/pitrz/manual.htm). Treat its encoder instructions as historical; use the current [Video Playback](https://nathanneurotic.github.io/Simple-Media-System/video.html) page for SMS's actual playback limits.
